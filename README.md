# Slate Studio

A Blender-like 3D animation and sculpting studio in a single web page, built for iPad. Used to block scenes, cameras and acting for "The Bungalow Between Worlds".

- **Run it:** open `index.html` (or the GitHub Pages link once enabled). Keep the `assets/` folder next to it.
- **Build it:** `bash build.sh` (needs bash and node). Source lives in `src/`.
- **Work on it with an AI assistant:** point it at this repo and `AGENTS.md`.
